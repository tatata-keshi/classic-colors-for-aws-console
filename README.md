# AWS Console Classic Colors

AWS マネジメントコンソールのヘッダー・リンク・プライマリボタンの色を、以前の配色風に戻す Chrome 拡張機能です。
ツールバーのアイコンから、全体の有効/無効、パーツごとの有効/無効、色の変更ができます。

## インストール（開発者モード）

1. このリポジトリを clone、または ZIP をダウンロードして展開します。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択します。

## 設定

| 項目 | 内容 | 既定色 |
| --- | --- | --- |
| ヘッダー | ナビゲーションバーと検索欄 | `#232f3e` |
| リンク | 本文・サイドバーのリンク | `#295eff` |
| プライマリボタン | 「インスタンスを起動」などのボタン | `#ec7211` |

設定は `chrome.storage.sync` に保存され、同じ Google アカウントの Chrome 間で同期されます。

## 対象ドメイン

AWS マネジメントコンソール（グローバル / 中国 / GovCloud）と AWS Health Dashboard に対してのみ動作します。

## プライバシー

この拡張機能はページに CSS を差し込むだけです。閲覧内容の読み取り・収集・外部送信は一切行いません。ネットワーク通信もありません。必要な権限は設定保存用の `storage` のみです。

## 注意

- AWS コンソールの内部クラス名に依存しているため、AWS 側の変更で効かなくなることがあります。
